# Global Courier Platform

A doorstep international courier platform helping Indian families send permitted parcels to relatives abroad.

## Applications

- Customer Portal: Courier booking, parcel details, payments and tracking.
- Driver Portal: Pickup assignments, verification and parcel collection.
- Admin Portal: Customer, driver, booking and shipment management.

## Technology Stack

- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Python, FastAPI
- Database: Supabase PostgreSQL
- Authentication: Supabase Auth
- Storage: Supabase Storage
- Version Control: Git and GitHub

## Core Workflow

Customer Booking ? Driver Assignment ? Doorstep Pickup ? Packing ? Hub Processing ? International Courier Partner ? Delivery.
