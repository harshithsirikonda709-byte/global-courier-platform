# Global Courier Platform

A doorstep international courier platform helping families in India send eligible parcels to relatives and friends abroad.

## Applications
- Customer Portal: booking, parcel details, payments and tracking.
- Driver Portal: pickup assignments, verification and parcel collection.
- Admin Portal: bookings, drivers, shipments, partners and operations.

## Technology Stack
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Python, FastAPI
- Database: Supabase PostgreSQL
- Authentication: Supabase Auth
- Storage: Supabase Storage
- Version Control: Git and GitHub

## Core Workflow
Customer Booking → Admin Assignment → Driver Pickup → Packing → Company Hub → Authorized International Courier Partner → Customs → Delivery.

## Repository Structure
- frontend/customer
- frontend/driver
- frontend/admin
- backend/app
- database/migrations
- docs

## Development Rules
- Do not push directly to main after initial setup.
- Use assigned feature branches.
- Submit pull requests for review.
- Never commit API keys, passwords or .env files.
- Test features before marking them complete.

## Important
International shipping is fulfilled through appropriately authorized courier partners. Shipment eligibility depends on destination-country regulations.
